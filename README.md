## איך פותחים את האתר

- **מקומית:** פותחים את הקובץ `index.html` בדפדפן — זה הכול, אין צורך בהתקנה.
- **באינטרנט (GitHub Pages):** בהגדרות המאגר ב-GitHub: Settings ← Pages ← בוחרים את הענף ושומרים. האתר יקבל כתובת קבועה שאפשר לפתוח מהנייד.

## איך האתר מתעדכן

1. **שינוי של חברת התעופה או הזמנה חדשה:** מעדכנים את הקובץ `data.js` (אפשר לבקש מ-Claude לעדכן לפי המייל החדש) — האתר מציג מיד את הנתונים החדשים.
2. **הוספה מהירה מהדפדפן:** בכל תיק יש כפתורי "+ הוספת שירות" ו"+ הוספת טיול". התוספות נשמרות בדפדפן (localStorage).
3. **גיבוי וסנכרון:** הכפתור "⬇️ ייצוא נתונים מעודכנים" מוריד קובץ JSON עם כל הנתונים כולל התוספות — אפשר לשלוח אותו ל-Claude כדי לעדכן את `data.js` לצמיתות.

## מבנה הקבצים

- `index.html` — דף האתר
- `data.js` — כל נתוני הטיסות, ההזמנות והטיולים (מקור האמת)
- `app.js` — לוגיקת התצוגה וההוספה
- `style.css` — עיצוב
